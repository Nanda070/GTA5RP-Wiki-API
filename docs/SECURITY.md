# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

This library only fetches and parses publicly available wiki HTML. If you discover a security issue in **this repository** (e.g. unsafe handling of untrusted HTML that could affect consumers), please open a private advisory or contact the maintainer via GitHub.

Do not use this project to overload [wiki.gta5rp.com](https://wiki.gta5rp.com). Keep request concurrency and poll intervals reasonable.
